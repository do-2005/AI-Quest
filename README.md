# **Daleelak**
- It's an interactive, smart web portal designed to clarify and guide users regarding government services, official procedures, and court litigation filing processes, featuring a simulated AI system to evaluate and prioritize court cases. It also supports both Arabic and English languages.

# **Features**
- chatbot : gives you the required documents ,location,fees and time for each service .
- Automated Load-Balancing & Smart Court Routing: Automatically detects heavy workloads in busy courts and routes new cases to less-congested branches to prevent delays and balance the system.
- Intelligent Case Distribution :Auto-transfers urgent cases to less busy courts.
- The court process and filing cases : simuliting case detail entry with automatic evaluation of urgency and importatnt using AI-like algorithm.
- Arabic & English Localization: Dynamic language switching between Arabic and English.
# **Tech stack and design**
- **HTML5** : 	Semantic elements; dynamic lang and dir for both languages.
- **CSS3** : 	Grid and Flexbox, CSS custom properties, media queries for responsiveness and dark mode, logical properties for RTL/LTR.
- **Vanilla JavaScript** : State management, UI rendering, input validation, scoring and transfer rules.
- **Google Fonts** : Arabic/Latin font, with a fallback when offline.
